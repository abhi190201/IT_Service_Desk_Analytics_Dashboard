# Power BI Build Guide

### Executive Overview
Cards: Total Tickets, Resolution Rate, SLA Compliance, Avg Resolution Hours, Open Backlog.
Charts: Monthly ticket trend, Tickets by Category, Tickets by Priority.

### SLA & Performance
Charts: SLA Compliance by Priority, SLA Breaches by Category, Average Resolution Hours by Priority.

### Ticket Analysis
Charts: Ticket Status distribution, Category distribution, Monthly volume trend.

### Agent Performance
Table: Agent, Tickets Handled, Avg Resolution Hours, SLA Compliance %.
Add slicers for Date, Category, Priority, Agent and Status.

### Data Model
For a simple portfolio project, a single fact table is sufficient. For an advanced version, create Date, Agent, Category and Priority dimension tables.
