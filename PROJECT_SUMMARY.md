# Project Summary

**IT Service Desk Analytics Dashboard** | SQL, Excel, Power BI, DAX, Power Query

Analyzed 1,200 synthetic IT service desk tickets using SQL and Excel to track SLA compliance, resolution time, ticket categories, priority, agent performance, backlog, and monthly trends. Built an interactive Power BI dashboard with DAX and Power Query for KPI monitoring and operational insights.

## Resume bullets
- Analyzed 1,200 service desk tickets using SQL and Excel to evaluate SLA compliance, resolution time, ticket categories, priority, backlog, and monthly trends.
- Built an interactive Power BI dashboard using Power Query and DAX to monitor KPIs and identify SLA breaches and support-performance trends.
