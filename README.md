# IT Service Desk Analytics Dashboard

## Objective
Analyze IT service desk tickets and monitor SLA compliance, resolution time, ticket categories, agent performance, backlog, and monthly trends.

## Dataset
`data/service_desk_tickets.csv` contains 1,200 synthetic service desk tickets generated for portfolio/learning use.

## Tools
- SQL
- Excel
- Power Query
- Power BI
- DAX

## Power BI Dashboard
Create a Power BI report using the CSV as the source. Recommended pages:
1. Executive Overview
2. SLA & Performance
3. Ticket Analysis
4. Agent Performance

## Recommended KPIs
- Total Tickets
- Resolution Rate %
- SLA Compliance %
- SLA Breaches
- Average Resolution Hours
- Open Backlog

## Important
The dataset is synthetic and should be described as a portfolio/learning project, not as confidential employer data.
